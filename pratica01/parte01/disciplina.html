INF 321 - PROJETO E DESENVOLVIMENTO DE SISTEMAS PARA A WEB

Descrição

A disciplina Projeto e desenvolvido de sistemas para a web tem como objetivo introduzir ao aluno conceitos arquiteturais básicos da Web, focando em aspectos de projeto e implementação de sistemas e softwares para a mesma; Treinar o desenvolvimento de aplicações cliente-servidor e de sistemas com comunicação por troca de mensagens; Treinar o desenvolvimento de aplicações multiplataforma; Introduzir o aluno à linguagens de marcação e de folhas de estilo; Prover contato inicial do estudante com tecnologias de desenvolvimento backend; Introduzir, por meio de aplicações Web, conceitos de comunicação assíncrona cliente-servidor e acesso a bancos de dados no servidor.

Professor: Lucas Vegi
